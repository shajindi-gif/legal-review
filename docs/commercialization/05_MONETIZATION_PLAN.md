# 05 商业闭环与定价方案（Monetization Plan）

> 原则：只选经过论证的 1-2 种商业模式；所有无真实数据的指标=假设，必须带验证方式；不编造收入。

---

## 1. 商业模式选择

**主模式：订阅 SaaS（按账号年/月订阅）**
理由：① 审查任务随文件产生，频次中等但持续（政策刚性），订阅匹配预算方式（政务/事业单位按年度预算采购）；② 竞品锚点验证——法宝 ¥2500-3600/年、幂律 ¥5999+/年 均为年度订阅且公开可查（02 §2）；③ 现有系统（UserPlan/Order/QuotaService）就是订阅制实现，改造成本为零。

**辅模式：私有化部署（企业版延伸，政务大客户）**
理由：数据不出域是政务买家的硬顾虑；对标 Luminance「平台费+席位费」结构（02 §3.3）。近期只报价不主动销售，等有真实询单再启动。

**明确不用**：Credits 积分制（政务用户理解成本高、预算科目不匹配）、按次付费（削弱复用动机、客单价低）。

## 2. 商业闭环漏斗（逐环节设计）

| 环节 | 现状堵点 | 设计 |
| --- | --- | --- |
| 流量获取 | 无内容层 | 见 06（3 渠道：SEO/GEO、知乎专栏、行业协会/政务社群） |
| 访问→理解 | 信任层缺失 | 首页改造（03 §2）：政策依据+证据演示 |
| 访问→注册 | 定价页不可见 | /pricing 公开化 |
| 注册→激活 | Onboarding 与首任务脱节 | 注册即引导上传第一份文件；免费 2 次跑**完整流程** |
| 激活→付费 | 429 文案技术化 | UpgradeDialog：价值回顾+升级直达 |
| 付费→复用 | 导出缺失 | docx 导出+「继续下一份」钩子 |
| 复用→续费 | 无提醒 | 到期前 30/7 天站内通知（已有通知中心） |
| 续费→推荐 | 无机制 | 真实案例页；转介绍政策待有客户后设计（不提前承诺） |

## 3. 定价体系（保持三档，修正语义）

| 档位 | 价格（现网实价） | 提供价值 | 升级动因 |
| --- | --- | --- | --- |
| 免费体验 | ¥0，**累计 2 次完整审查**（修正原「每日 3 次」错误文案） | 全流程可用：上传→审查→意见书在线查看 | 用量+归档需求 |
| 专业版 | ¥299/月 · ¥837/季（≈279/月）· ¥2990/年（≈249/月） | 无限次审查、全量法规库（含地方法规）、深度报告+修改建议、工作日 8h 响应 | 县级司法局单科室主力档 |
| 企业版 | ¥1999/月 | 企业版权益+自定义法规库+团队账号（≤50 人）+私有化部署支持 | 多部门/市级/大数据局 |

**定价依据（非拍脑袋）**：
- 法宝账号级产品 ¥2500-3600/年（02 §2.3）→ Pro 年付 ¥2990 落在同区间，且提供的是「专用审查工作流」而非法规库查询，支持溢价定位；
- 幂律基础版 ¥5999/年（02 §2.4）→ 上方留出升级空间；
- 县级司法局年度信息化预算通常在万元级（**假设，验证方式：与 3 个目标县科室做价格访谈**）；Pro 年付单账号在个人/科室小预算可决策范围内，企业版留给预算更大的采购。

**建议调整（待验证后实施）**：
1. 企业版主推**年付 ¥19,990/年**（现 ¥1999/月等价，标省 ¥3,998），匹配政务年度预算周期；
2. 新增「对公转账+发票」入口（线下闭环兜底，支付宝仅覆盖线上小额）；
3. 不做免费版永久档——免费=体验 2 次，避免「免费 poorest experience」伤害口碑。

## 4. 单位经济模型（全部为估算/假设，标注验证方式）

### 4.1 单次审查边际成本（LLM）

**假设**（待 agent_logs 实测回填）：
- 单次审查消耗：输入 15–30 万 tokens（文档+检索片段×多节点）、输出 1–3 万 tokens（11 节点结构化输出）
- 模型路由：DeepSeek 官方刊例（2026-10 查询，https://api-docs.deepseek.com/zh-cn/quick_start/pricing ）：v4-flash 输入缓存未命中 $0.3/M（峰值）、v4-pro $1.32/M（峰值）；输出价以刊例页为准。汇率按 7.2 估算。
- 估算区间：**单次审查 LLM 成本 ≈ ¥0.4 – ¥3.5**（flash 路由下限 / pro 全程上限）；Embedding 本地 BGE-M3 无 API 成本。
- **验证方式**：agent_logs 已存 usage tokens（M 系列修复后完整保留）→ 上线成本统计 SQL，按周回填真实值替换本区间。

### 4.2 单用户月成本（Pro 用户假设：月均 20 份审查）

LLM：20 × ¥0.4–3.5 = ¥8–70/月；服务器分摊：单机 4C8G 轻量云 ¥150/月 ÷ 用户数（**假设**初期 <50 用户，分摊 ¥3-30/月）；支付通道：支付宝费率 ~0.6%（以签约费率为准）。
→ **单 Pro 用户月边际成本 ≈ ¥11–100，占 ¥299 定价的 4%–33%，毛利 67%–96%。**
**验证方式**：Prometheus+agent_logs 实测 token 消耗分布；若高频用户成本超 ¥100/月，引入「fair-use 单日上限」而非涨价。

### 4.3 获客成本（CAC）目标

**全部为假设**：假设内容渠道为主（近零现金成本，人力投入），首批 10 个付费客户目标 CAC < ¥1,000（≈3.3 个月 Pro 月费）。
**验证方式**：07 埋点上线后按渠道归因实测；CAC > ¥2,000 时停止该渠道投入。

### 4.4 LTV 目标（假设）

政务订阅续费率**假设 60%–80%**（续费取决于真实使用频次，无数据前不承诺）。LTV(Pro 年付) ≈ ¥2990 × 平均存续 2 年 × 毛利率 ~85% ≈ **¥5,000/用户**。
**验证方式**：以首批付费用户 cohort 实测 D30/D90 活跃与续费。

## 5. 付费转化机制细节

1. **免费 2 次的设计意图**：第 1 次建立信任（完整流程+证据引用），第 2 次验证复用（换一份自己的文件）。用尽时 UpgradeDialog 展示「已为你完成 2 份审查」+上次报告链接（资产沉淀感）。
2. **支付渠道成本**：支付宝当前唯一在线渠道（费率以签约为准 ~0.6%）；对公转账作为大额兜底；微信支付待商户资质（不做假入口）。
3. **发票**：企业版/对公必配；个人 Pro 标配电子普票。开票信息来自 siteInfo 主体字段（待运营方填入）。
4. **退款政策**：7 天内未使用可全额退（写入用户协议，降低首次付费心理门槛）；已产生审查记录按使用量比例处理（法务审核后定稿）。

## 7. 合规与安全底线（不可妥协）

- 价格与促销文案与实际权益一致（修 P0-2 虚假宣传风险）
- 支付回调验签/金额校验/幂等已实现（PaymentService），升级引导改造不得绕过
- 政务采购可能要求等保/信创——列为私有化销售前置检查项（**未知**，逐单确认）
