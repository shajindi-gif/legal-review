## 4. 功能审计：真价值 vs Demo

| 模块 | 判定 | 说明 |
| --- | --- | --- |
| 11 节点审查流水线 + SSE | **真价值，主打** | 垂直 AI 核心差异，应放首页第一屏 |
| 证据引用（EvidenceCard/法规条款） | **真价值，被低估** | 政务买家最在乎「依据可查」，未作为首页卖点 |
| 报告/审查意见书 | 真价值 | 需验证导出（PDF/docx）是否可用 ◐ |
| Assistant 对话 | 边缘 | 与主任务弱相关，M11 交付但无入口策略，暂隐藏引流 |
| 历史记录/通知/反馈 | 支撑功能 | 保留，不出现在首屏 |
| 评估系统（golden dataset） | 内部能力 | 不对用户暴露，转化为「准确率数字」对外呈现 |
| 微信支付前端入口 | **半成品** | 定价页保留微信渠道选择但提示「线上支付与开票功能正在接入中」——与已上线的支付宝矛盾，造成「不能付钱」错觉 |

## 5. P0-P3 问题总清单

**P0（阻碍转化/合规硬伤，本周内必须修）**
1. /pricing 未登录被重定向登录页 → 游客无法看价格
2. 首页「体验版 每日 3 次」与实际累计 2 次矛盾 → 虚假宣传风险
3. 定价页「线上支付与开票功能正在接入中」过时提示 → 用户以为不能付款
4. 注册页无用户协议/隐私政策勾选 → 个保法合规风险
5. Footer ICP/主体信息空白占位 → 上线合规硬伤（**需运营方提供备案号与主体信息，代码侧无法代填**）

**P1（显著影响体验/转化）**
6. 首页无社会证明（案例/数据/背书）与 FAQ
7. 无 SEO 内容层（sitemap/robots/解决方案落地页）
8. 无任何数据埋点 → 转化漏斗不可观测
9. 定价页信息架构弱（无单位价格锚点、无「推荐」徽标的决策辅助）
10. 报告导出/归档链路待验证与补强（复用理由）

**P2（优化项）**
11. /login、/register `_rsc` 预取 ERR_ABORTED
12. 首页技术参数堆砌（DeepSeek/BGE-M3）对买家无意义，应换业务语言
13. 免费额度剩余次数展示不够醒目（应常驻+用尽时强引导）
14. Onboarding 已有对话框但与首任务衔接弱

**P3（长期）**
15. 多租户隔离仅覆盖 tasks 路由（documents/notifications/feedback/assistant 未接入）
16. 微信支付启用（等商户资质）
17. Alertmanager 告警通知落地
